# Skill Swap BD

Web app to swap skills with others instead of paying — e.g. trade guitar lessons for web dev help.

## Tech Stack
ASP.NET Core MVC · EF Core · SQL Server · Bootstrap 5 · ASP.NET Identity

## Features
- Register/Login
- Post skills (Offer/Want)
- Browse & search skills
- Request, accept/reject, complete swaps
- Rate & review after a swap

## Setup
1. Clone repo
2. Update `appsettings.json` connection string
3. `dotnet ef database update`
4. `dotnet run`
